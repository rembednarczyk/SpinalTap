# Testowy model VRoid

`vroid-sample-e.vrm` to próbka „ビビ” (AvatarSample_E) od VRoid Project, pobrana z
OpenGameArt (`avatarsample_e.zip`). Licencja zapisana w metadanych VRM (VRoid Hub license v1):
użycie przez każdego, modyfikacja, redystrybucja i użycie komercyjne dozwolone, bez wymogu
atrybucji.

Leży w repo tylko do testów importu modeli (retarget kości, materiały, wydajność).
Nie jest to docelowy wygląd Seki. Włączenie: `?models=./models/test/manifest.json`.
